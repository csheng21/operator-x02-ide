## 🛡️ Ship safety-critical with confidence

Tuned for **MISRA C:2012**, **ISO 26262**, **IEC 61508** and **IEC 62304** — purpose-built for ADAS and safety-critical embedded work:

- **ISO 26262 Professional Analysis** — one click on any AI-proposed change generates a full clause-cited report: Executive Summary, ASIL impact, compliance status, risk assessment, and per-change safety breakdowns. Save as HTML for review.
- **Engineering Assessment Report** — evidence-driven findings with stable IDs, a published scoring formula, severity heatmap, prioritized actions with verification checklists, and a machine-readable `assessment.json` twin. Every number has computable provenance.
- **AI-aware SVN & Git** — native TortoiseSVN *and* Git: real modified files, AI-written commit messages, diff analysis, merge help on request.

## ⬇ Two ways to get X02

### ⭐ Recommended — Download Installer

**All features fully working. No build required.** Compiled by the dev team with the complete codebase.

👉 [**Download for Windows — Free**](https://github.com/csheng21/operator-x02-ide/releases)

> ⚠ **Windows 10 / 11 (64-bit) only.** macOS + Linux coming in v1.6.x.

### 🛠️ For developers — Build from Source

Clone, study, and contribute.

```bash
# prerequisites: Node 18+, Rust 1.70+
git clone https://github.com/csheng21/operator-x02-ide.git
cd operator-x02-ide
npm install
npm run tauri dev
```

> ⚠ **Note:** 4 core modules (incl. Surgical Edit Engine, NVIDIA Jetson, SSH Remote Manager) are community stubs when built from source. Download the installer for the full experience.

<details>
<summary><b>📋 Full prerequisites & first launch</b></summary>
<br/>

- **Node.js 18+** — https://nodejs.org
- **Rust 1.70+** — `winget install Rustlang.Rustup`
- **Visual Studio C++ Build Tools** — select *"Desktop development with C++"*
- **WebView2** — usually pre-installed on Windows 10/11
- **Optional:** [arduino-cli](https://arduino.github.io/arduino-cli/) for Arduino · [TortoiseSVN](https://tortoisesvn.net/) (with CLI tools) for SVN · ADB is **installed automatically**

On first launch, app folders are created at `C:\Users\{you}\OperatorX02\` — config, conversations (local & private), projects, plugins, backups, logs. Add providers in **Settings → AI Providers**, or just use the free built-in AI.

</details>

<details>
<summary><b>🔧 Troubleshooting</b></summary>
<br/>

- *Linker not found* → install VS C++ Build Tools, restart terminal
- *WebView2 not found* → https://developer.microsoft.com/microsoft-edge/webview2/
- *ADB not detected* → click **Install ADB Automatically** in the Android panel
- *SVN not working* → reinstall TortoiseSVN with **command line client tools** checked
- *AI not responding* → check the API key in Settings, use the free built-in AI, or run Ollama offline
- *Slow on large projects* → F12 console: `window.X02Perf.throttle(5)` / `window.X02Perf.restore()`

</details>
